# MVP Mercados VIVA

Aplicación web desarrollada como MVP para resolver el proceso de consulta y actualización de inventario de Mercado VIVA.

## Tecnologías

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI

### Base de datos y autenticación
- Supabase
- PostgreSQL
- Supabase Auth

## Roles

### Cliente
- Consultar productos
- Agregar productos al carrito
- Confirmar compras
- Validación de stock al momento de confirmar

### Auxiliar
- Consultar inventario
- Actualizar existencias

## Arquitectura

Frontend → FastAPI → Supabase
